## 当前使用范围

MakerWorld 中国站模型链接 → NexPrint 草稿／创想云仅自己可见。工具使用设备默认 Chrome 中已有的登录状态。保存前需在 ModelPort 中核对资料及平台声明；公开发布由用户在目标平台完成。

“自动上传”指脚本处理上传控件、文件、图片和支持的表单字段。Chrome 的连接授权、平台登录验证、资料与许可核对，以及最终保存确认，仍可能需要用户操作。

## 第一阶段验收项

- [ ] 能找到首次启动、连接 Chrome、导入、保存和重试的完整步骤。
- [ ] 能区分“资料已收集”“待确认保存”“已保存”和公开发布。
- [ ] 能理解删除任务只删除本地记录，重新同步可能产生新的平台草稿或私密作品。
- [ ] 已列出当前字段、图片与许可的支持边界，没有把待验证能力写成保证。
- [ ] 视频按真实操作设计，包含 Chrome 授权、核对保存和失败处理。

请按文件名和章节指出需要修改的内容。第一阶段确认后，再开展第二阶段的逐项实测。

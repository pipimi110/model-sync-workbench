# ModelPort 快速开始

适用：Windows 桌面版 v0.1 · 第一阶段草稿 · 2026-10-15

目标：从一个 MakerWorld 模型链接开始，在 NexPrint 保存草稿，或在创想云保存为仅自己可见。第一次建议只选一个模型、一个目标平台，确认结果后再批量操作。

## 1. 启动工具

如果收到发布版 `ModelPort-版本-win-x64.exe`，直接双击即可运行，无需安装 Node.js；资料默认保存在 `%APPDATA%\ModelPort\data\`。详见[单文件 EXE 说明](packaging.zh-CN.md)。Chrome 的连接步骤与源码版相同。

以下为源码开发版启动方法，保留现有热加载流程：

打开 ModelPort 项目文件夹，双击 `start.cmd`。出现“ModelPort · 模型同步工作台”窗口后即可操作。

如果提示缺少依赖，在项目文件夹打开 PowerShell，按顺序执行：

```powershell
npm.cmd install --registry=https://registry.npmjs.org
npm.cmd run setup-desktop
npm.cmd start
```

源码运行需要 Node.js 22 或更高版本。该启动方式不是独立安装包；不要只复制 `start.cmd` 到其他目录运行。

## 2. 连接设备上的 Chrome

1. 打开日常使用的 Chrome 稳定版；当前连接方式按 Chrome 144 或更高版本准备。
2. 在 Chrome 地址栏输入 `chrome://inspect/#remote-debugging`，启用远程调试。
3. 回到 ModelPort，点击左侧“平台与账号”→“连接默认 Chrome”。
4. 如果 Chrome 请求允许本次调试连接，核对是本次连接后点击“允许”。
5. 确认 ModelPort 显示“设备默认 Chrome 已连接”。

这里使用已有 Chrome 登录状态，不需要导出 Cookie，也不需要安装 ModelPort 浏览器扩展。当前程序读取 Chrome 稳定版标准用户目录中的调试端点；其他浏览器、Beta／Canary 和自定义用户目录不在这份快速开始的适用范围内。

Chrome 的启用入口及会话授权方式可参阅 [Chrome 官方说明](https://developer.chrome.com/docs/devtools/agents/use-cases/auto-connect?hl=zh-cn)。该页面还介绍了其他工具的配置；使用 ModelPort 时按本节连接按钮操作即可。

## 3. 确认平台登录

在“平台与账号”中，分别点击 MakerWorld 和所需目标平台的“在默认 Chrome 打开 ↗”。如果页面要求登录、验证码或验证，请在 Chrome 中完成。

“Chrome 已连接”只代表浏览器连接正常，不代表三个平台都已登录。不要把密码填进模型链接输入框。

## 4. 添加模型链接

1. 点击“模型库”→“添加模型链接”。
2. 粘贴模型详情页链接；多个链接每行一个。
3. 点击“读取链接并添加”。
4. 等待模型资料收集；出现“待补充”时，打开“管理资料”查看原因。

以下链接格式均可输入，示例只用于说明格式：

```text
https://makerworld.com.cn/zh/models/3101479-yuan-shen-qi-tian-shen-xiang-feng-shen-shen-xiang
https://makerworld.com.cn/zh/models/3101479-yuan-shen-qi-tian-shen-xiang-feng-shen-shen-xiang#profileId-3651936
https://makerworld.com.cn/zh/models/3101479-yuan-shen-qi-tian-shen-xiang-feng-shen-shen-xiang#profileId=3651936
```

当前入口接受中国站的 HTTPS `/zh/models/` 模型详情页，不接受作者上传列表、其他平台链接或本地路径。

## 5. 核对并保存模型资料

点击模型卡片上的“管理资料”，逐项检查：

- **模型名称与模型说明**：保留需要的来源、署名和使用说明。
- **创作类型与源站许可**：按实际权利选择；复制自己账号的作品也不等于一定属于原创。
- **打印配置**：将份数与源站对照，检查每份配置是否有下载文件。
- **图片用途与封面**：为每张图片选择“实拍照片”“渲染图”或“说明 / 示意图”，并选择“作为封面”。创想云封面须为确认过的实拍照片。
- **目标分类与标签**：选择合适的分类、用逗号分隔标签；目标平台的具体支持边界见[使用手册](user-guide.zh-CN.md)。

点击“保存资料”。遇到文件缺失，可先“重新读取来源资料”；必要时用“＋ 添加 3MF”或“＋ 添加图片”补充文件。

## 6. 发起同步

1. 在模型卡片上勾选要同步的作品。
2. 点击“预览同步 →”。
3. 勾选 NexPrint 或创想云；先只保留本次要操作的目标。
4. 阅读阻止项和提示，补齐资料后再预览。
5. 点击“开始同步 →”，在“同步任务”中查看进度。

工具会自动准备目标平台表单。NexPrint 的上传控件初始化、3MF 解析、封面裁剪确认和图片上传均由脚本处理；等待时不用反复点平台上传按钮。

若页面出现登录或验证要求，先按平台正常流程完成。若日志长时间不变或出现错误，请查看[故障排查](troubleshooting.zh-CN.md)，不要直接把仍显示“准备中”的任务当成保存成功。

## 7. 核对并确认保存

任务变成“待确认保存”后：

1. 点击“核对并保存”。
2. 同时查看 Chrome 中的目标表单，检查文件、图片、说明、许可及目标账号。任务截图只是一张当前视口截图，不能代替检查整个表单。
3. 创想云还需阅读本次展示的《模型声明》，确认“只对自己”。
4. 勾选核对确认项，点击“确认保存”。
5. 等待任务变成“已保存”，再通过“查看作品 ↗”核对目标平台。

| 目标平台 | 本轮正常结果 |
| --- | --- |
| NexPrint | 模型出现在草稿箱，任务显示“已保存草稿” |
| 创想云 | 模型保存为“只对自己”，任务显示“已保存为仅自己可见” |

“待确认保存”还没有保存；“已保存”也不表示公开发布。需要公开时，请之后在平台上自行完成。

## 8. 中断、删除与重试

想停止准备过程，可点击“中断同步”；排队任务可“取消排队”。“保存中”阶段会先核验结果，此时不能中断或删除。

想清掉旧记录再建任务，可点击“删除任务”，运行中的任务则点击“中断并删除”。之后回“模型库”重新选择模型并预览同步。删除只清理工作台记录，模型素材和目标平台作品保留；已保存过的模型再次同步，可能产生新的草稿或私密作品。

误删记录可在“同步任务”→“已删除（数量）”中点击“恢复记录”。恢复记录不会重新上传；若已经为同一模型和平台建立了新任务，须先处理新任务。

如果任务显示保存结果不明确，先查目标平台：已有作品就记录其链接；确认没有作品后再重新准备。具体步骤见[故障排查](troubleshooting.zh-CN.md)。

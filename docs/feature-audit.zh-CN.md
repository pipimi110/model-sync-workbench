## 1. 文档依据

| 能力 | 代码依据 | 第一阶段结论 |
| --- | --- | --- |
| Windows 桌面启动 | [start.cmd](../start.cmd)、[桌面入口](../desktop/main.cjs) | 依赖已安装时可双击启动；源码要求 Node.js 22+，未提供独立安装包 |
| 连接默认 Chrome | [浏览器管理](../src/browser.mjs) | 使用 Chrome 稳定版标准目录的调试端点；不启动独立平台登录配置 |
| 支持的模型链接 | [来源解析及预览](../src/domain.mjs) | 中国站 HTTPS `/zh/models/`，支持无片段、`profileId-` 和 `profileId=` |
| 资料和 3MF 自动收集 | [MakerWorld 采集](../src/adapters/makerworld.mjs) | 按页面识别结果处理；配置和图片完整性仍需对照源站 |
| 图片用途、封面与资料编辑 | [界面](../ui/app.js)、[服务](../src/service.mjs) | 用户确认用途、创作类型与许可；这些判断未自动化 |
| 软件作者与版权声明 | [账号页](../ui/app.js)、[页脚](../ui/index.html) | 静态显示 ModelPort 作者及版权归属，不属于模型资料或上传表单 |
| 目标字段和许可映射 | [目标适配器](../src/adapters/targets.mjs) | 两个平台的支持范围不同，不能合并描述成所有资料原样迁移 |
| 待确认后才保存 | [队列](../src/queue.mjs)、[界面](../ui/app.js) | 保存需本轮核对确认；公开发布不在自动流程中 |
| 中断、删除、恢复与去重 | [队列](../src/queue.mjs)、[持久化](../src/store.mjs)、[文件删除](../src/deletion.mjs) | 模型、任务支持回收站和彻底删除；模型资料支持永久删除单份 3MF；图片删除为永久清理；文件清理保护共用文件并支持失败回滚；目标平台作品保留 |
| 隔离测试 | [核心测试](../test/core.test.mjs)、[删除专项](../test/deletion.test.mjs)、[桌面界面](../test/library-ui.test.mjs)、[HTTP 测试](../test/server.test.mjs) | 覆盖来源、队列、删除恢复、文件清理和界面交互；测试不登录、不开真实上传页面 |

Chrome 调试设置入口另对照了 [Chrome 官方说明](https://developer.chrome.com/docs/devtools/agents/use-cases/auto-connect?hl=zh-cn)。ModelPort 自身使用本地代码中的 CDP 连接，不要求用户照抄该文档里的其他工具配置。

## 2. 当前必须如实披露的边界

| 项目 | 当前事实 | 文档如何表述 |
| --- | --- | --- |
| NexPrint 分类与标签 | 模型编辑页有字段，但 NexPrint 分支未调用对应填写操作 | 需在目标表单核对／补充，不宣称自动填写 |
| NexPrint 许可 | 自动问卷映射当前仅实现 Standard Digital File License | 识别到其他源许可不代表可以自动提交到 NexPrint |
| 创想云渲染图 | 上传分支处理实拍和说明图，未覆盖独立 `render` 用途 | 图库不保证保留所有来源图，需检查补充 |
| 多打印配置 | 上传原始文件与目标平台原生配置结构不是同一概念 | 逐份检查文件及转换后的切片参数 |
| 说明格式 | 来源描述按文字采集 | 不保证富文本版式、内嵌视频、图文位置关系原样恢复 |
| 图片采集上限 | 最多尝试前 30 张候选图片，单张超过 20 MB 跳过 | 用户对照源站补齐需要的素材 |
| NexPrint 保存核验 | 当前按草稿标题匹配 | 同名作品需人工打开核对，不声称远端严格去重 |
| 任务截图 | 当前视口截图 | 只作辅助证据，不替代整张表单核对 |
| 登录与连接 | Chrome 调试连接和各站账号登录独立 | “已连接”不等于所有站点已登录 |
| 应用重启 | 浏览器准备表单不可靠恢复 | 重启后检查目标结果并重新准备，不能继续使用旧确认 |

第一阶段只核对并记录上述边界，不扩大为功能开发。第二阶段若发现文档无法对应实际操作，先列明差异并修正文档；若需要补功能，再明确列出修复内容。

## 3. 真实平台验证记录的范围

此前风神像模型已经在 NexPrint 保存过草稿，在创想云保存过仅自己可见的作品。早期过程中有用户手动补点，不能把这些保存记录当成“无人干预完整同步”的证据。

最近一次修复后，风神像单配置模型由应用自行完成 NexPrint 的真实文件选择、3MF 上传／解析、封面裁剪确认和 8 张附图上传，并进入“待确认保存”。该轮没有通过浏览器人工补点，也没有新增草稿。此证据仅覆盖这一模型的表单准备，不扩大为所有模型、所有配置和所有平台的保证。

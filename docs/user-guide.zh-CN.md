# ModelPort 使用手册

适用：Windows 桌面版 v0.1 · 第一阶段草稿 · 2026-10-15

第一次使用请从[快速开始](quick-start.zh-CN.md)进入。本手册解释各页面、任务状态与当前支持边界；具体平台页面仍将在第二阶段逐项实测。

使用参考视频：[Bilibili 使用视频](https://www.bilibili.com/video/BV154JU6mEXo)。

## 1. 同步流程与需要确认的内容

基本流程：连接默认 Chrome → 导入 MakerWorld 链接 → 核对模型资料 → 预览同步 → 自动准备表单 → 核对并确认保存 → 查看目标平台结果。

脚本自动读取与上传支持的内容。用户负责平台登录验证、图片用途、创作类型、许可、表单及平台声明的核对。公开发布是之后在目标平台进行的独立操作。

## 2. 四个主要页面

| 页面 | 可以做什么 |
| --- | --- |
| 模型库 | 添加链接、搜索模型、管理资料、删除／恢复模型、选择作品并预览同步 |
| 同步任务 | 查看每个“模型 → 目标平台”的任务、核对保存、中断、删除、恢复、重试和查看结果 |
| 平台与账号 | 连接设备默认 Chrome，在同一浏览器中打开三个平台 |
| 运行记录 | 查看最近 500 条本地日志，定位最后执行的步骤 |

同一个模型选择两个目标平台会生成两个任务。队列逐个准备表单；存在其他正在操作浏览器的任务时，保存按钮对应的请求可能要求稍后再执行。

“平台与账号”页底部显示 ModelPort 软件的开发者和版权声明。该声明只标示本软件署名，不要求用户为模型填写声明，也不会附加到模型说明。

## 3. 链接导入和素材

### 支持的来源

目前接受 `https://makerworld.com.cn/zh/models/模型ID-名称`，可带 `#profileId-配置ID` 或 `#profileId=配置ID`。不带配置片段的链接也能输入；能否取得全部配置取决于页面实际加载和识别结果。

一次可输入 1–50 个链接，每行一个。相同 MakerWorld 模型 ID 会返回同一份本地模型资料；若需要刷新已收集的内容，使用“管理资料”中的“重新读取来源资料”。

### 资料收集的范围

工具尝试读取标题、文字说明、许可、模型图片及当前页面识别出的打印配置，并自动下载对应 3MF。文件会在入库时检查内容，防止把登录页等 HTML 当作模型文件保存。

0.1.1 支持当前页面的标题结构，并通过点击没有链接的配置卡片识别各配置；下载前同时确认配置 ID 和卡片实际选中状态。对已采集完成的模型使用“重新读取来源资料”时，会重新下载并替换对应配置的文件记录，避免一直沿用旧文件。

不要仅凭“资料已收集”判断素材齐全。应将源站的配置份数、图片及说明与本地记录对照；页面显示更多配置而未全部解析时，工具会保留已取得的资料并提示补充。

当前图片采集最多尝试前 30 张候选图片，单张超过 20 MB 会跳过。源站说明按文字读取，复杂排版、内嵌视频以及图文位置关系不保证原样恢复。

### 补充文件

在桌面版的“模型资料”中，用“＋ 添加 3MF”或“＋ 添加图片”打开文件选择器。添加文件是补充现有模型资料，不会直接向目标平台上传。每份 3MF 配置旁的“删除 3MF”会移除配置并彻底清理本地副本；勾选确认并保存后执行，保存前可撤销。若其他模型仍引用同一文件，会保留该共用文件。

网页开发预览使用本机绝对路径补充文件，与桌面版的选择器不同。普通用户按桌面版流程操作即可。

## 4. 模型资料检查

| 字段 | 检查方法 |
| --- | --- |
| 模型名称 | 与源作品一致，必要时调整为适合目标平台的标题 |
| 创作类型 | 按实际选择原创、二次创作或分享；保留改编来源和署名 |
| 源站许可 | 与源站条款一致，未知许可会阻止开始；不要为了通过检查随意换许可 |
| 目标分类、标签 | 与模型内容相关；目标平台自动填写范围见下一节 |
| 模型说明 | 检查署名、来源链接、打印建议及其他必要说明 |
| 打印配置 | 逐份检查文件名、大小和配置份数，核对喷嘴、层高等参数 |
| 图片用途 | 每张图片都确认用途；实拍、渲染和说明图应按实际内容区分 |
| 封面 | 选择一张作为封面；同步到创想云时需为实拍照片 |

点击“保存资料”仅保存本地资料。任务正在上传、中断或保存时，暂不能编辑该模型。若准备表单后修改了资料，旧的保存确认会失效，需要重新准备。

### 删除图片和批量确认实拍

点击图片下方的“删除图片”会将它标记为彻底删除；勾选确认后点击“保存资料”，本地图片及其下载缓存会被清理。保存前可点击“撤销删除”或直接关闭窗口放弃修改。删除封面后可重新选择封面；未选时保存会清空封面引用。图片删除后无法从应用恢复。

“全部设为实拍”开关会将当前保留图片的用途批量改为实拍。关闭开关会恢复本次切换前的用途；也可以单独修改某张图片。用途仍应与实际内容一致，开关不判断照片内容。上述修改同样在“保存资料”后生效。

图片没有回收站。删除后不会在“重新读取来源资料”时自动加回。若要重新取得素材，可重新下载或通过“＋ 添加图片”主动导入。

### 删除和恢复模型

点击模型卡片的“删除”，选择删除方式。默认“放入回收站”，保留模型资料、文件及关联任务，可在模型库“回收站（数量）”中恢复。“彻底删除”需要勾选确认，将移除模型资料、关联任务、本地库的模型文件、图片、下载缓存和相关截图，无法通过回收站恢复。其他模型仍引用的共用文件、导入前的本地原件及目标平台作品保留。

模型处于采集中，或仍有排队、准备、待确认保存、保存等未完成任务时，需先完成采集、完成任务或删除相关任务。模型回收站内也可执行彻底删除。

在模型库点击“回收站（数量）”再“恢复模型”，可恢复模型及随该模型一起移除的任务；此前单独删除的任务保持删除。恢复后可正常管理资料和选择同步。重新导入同一个回收站模型的链接也会恢复原记录；彻底删除后重新导入会建立新记录。

## 5. 两个目标平台的差异

| 项目 | NexPrint | 创想云 |
| --- | --- | --- |
| 保存方式 | 草稿 | 只对自己 |
| 模型与配置 | 将本地配置文件交给模型上传组件；平台如何展示须核对 | 第一份文件作为主配置，全部原始文件同时作为模型文件上传 |
| 自动填写 | 名称、文字说明、创作类型、支持的许可、封面及其余已分类图片 | 名称、文字说明、创作类型、分类、标签、许可问卷、封面、实拍图库等 |
| 分类与标签 | 当前上传分支尚未自动填写，需在平台核对或补充 | 已实现自动选择／输入，需核对平台最终结果 |
| 图片 | 封面单独上传；在模型资料中勾选要同步的图库图片，最多 9 张。未勾选图片仍保留在模型库；表单会核对平台实际接收数量，数量不符或平台报超限时不会允许保存草稿 | 封面为实拍，图库取其余前 8 张实拍；说明图和更多实拍作为说明附件处理 |
| 渲染图 | 已有上传分支 | 当前独立标记为渲染图的图片未被该目标上传分支覆盖，需在平台检查补充 |
| 许可 | 当前自动问卷映射仅实现 Standard Digital File License | 已实现 Standard、CC0、CC BY、CC BY-SA、CC BY-NC、CC BY-NC-SA 的问卷答案映射 |
| 保存后核验 | 在草稿箱匹配模型标题 | 核对提交前“只对自己”选项和提交后详情页 |

能够识别源许可，不等于已经支持把它自动映射到所有目标平台。许可问卷有差异时，工具会停止并要求核对，不会自动改成更宽松的许可。

多配置的原始 3MF 被上传，不等于目标平台会生成与 MakerWorld 相同数量、相同参数的原生切片配置。创想云可能转换 Bambu／Orca 配置，打印前需要检查喷嘴、层高、耗材等参数。

要挑选 NexPrint 图库图片，在模型库打开“管理资料”，给图片选择用途，再勾选“上传至 NexPrint”。系统默认不勾选图库图片；封面会独立上传，图库最多勾选 9 张。同步预览会显示勾选数量，未勾选的图片仍留在模型库。

## 6. 同步预览与任务去重

在模型库勾选作品后点击“预览同步 →”，保留需要的目标平台。出现红色阻止项时，先补齐资料；提示项也应阅读。

开始后，工具按“来源模型 ID + 目标平台”查找本地任务。通常会保留现有任务，避免反复创建相同任务；已中断或已删除的记录不会阻止新建。

这只是本地任务去重，不会自动查询目标平台全部已有作品。删除旧的“已保存”记录再同步，可能生成另一个平台作品。

## 7. 任务状态

| 状态 | 含义与下一步 |
| --- | --- |
| 排队中 | 尚未开始；可以取消排队或删除 |
| 准备中 | 正在上传文件或填写表单；可以中断，或中断并删除 |
| 正在中断 | 正在结束该任务的页面操作；等待收尾 |
| 已中断 | 本轮准备流程已停止，没有执行本轮保存；可重新建任务 |
| 待确认保存 | 表单已准备，尚未确认保存；点击“核对并保存” |
| 保存中 | 已开始保存并核验，不可中断或删除；等待明确结果 |
| 已保存 | 已取得工具当前实现的核验结果；通过链接到平台核对 |
| 需要处理 | 常见于登录要求、字段变化或保存结果不明确；看消息与截图后处理 |
| 失败 | 本轮操作报错；查看日志与目标页面，判断是否可重新准备 |
| 正在删除 | 正在关闭未完成表单并移除本地任务记录；等待结束 |
| 已删除记录 | 仅在“已删除”列表中显示，可恢复记录 |

进度条是工作步骤提示，不是精确的网络传输百分比。平台显示的上传百分比也不等同于整个同步任务的完成度。

## 8. 核对保存和结果

“核对并保存”会展示当前任务截图和需要阅读的平台声明。截图只覆盖拍摄时的视口，请在 Chrome 中检查完整表单，特别是文件、图集、许可、目标账号和创想云可见性。

勾选确认项后点击“确认保存”。平台条款或模型声明需要本人确认时，应阅读后自行确认，不要把文档演示视为替你同意本次声明。

工具的“已保存”有具体核验范围：NexPrint 匹配草稿标题；创想云检查保存前可见性和保存后详情页。遇到同名旧草稿，还要打开核对文件、内容及时间，避免把旧记录当作新任务结果。平台审核状态与保存状态分别查看。

## 9. 中断、删除、恢复和重新同步

### 中断

“中断同步”停止正在准备的任务并关闭该任务专用页面。“取消排队”用于尚未开始的任务。中断不会撤销过去已保存到平台的模型；它也不能收回已经传输到平台的文件字节。

### 删除

“删除任务”可选择“放入回收站”或“彻底删除”。回收站保留记录及截图；彻底删除会清理记录和专用截图，无法恢复。准备中的任务会先中断，等异步收尾完成后再彻底删除；待确认保存的任务被删除时，其未保存表单会被丢弃。正在保存并核验的任务不可删除。

本地模型、3MF、图片和平台作品保留。删除后，本地“已同步到几个平台”等统计会按未删除记录重新计算；统计减少并不表示平台作品被删除。

### 恢复

进入“任务回收站（数量）”→“恢复记录”。这只恢复记录，不自动上传、不重新打开旧表单。原先待保存或运行中任务的表单已关闭，恢复后仍需重新准备；有同模型同平台的新任务时，恢复会被阻止以免产生冲突。

如果文件被占用或清理中断，应用会明确提示尚未清理完成。可点击“重试文件清理”；下次启动也会继续处理。资料写入失败时会回滚尚未提交的文件移动。

### 重新同步

确认目标平台当前结果后，回到“模型库”勾选作品，重新“预览同步 → 开始同步 →”。失败或需处理的原任务也可使用“处理 / 重试”。保存结果不明确时，优先核对并记录已有作品链接。

## 10. 重启、账号与数据

浏览器连接与平台登录是两件事。Chrome 连接断开后可重新连接；登录状态由日常 Chrome 配置维护。当前按一套默认 Chrome 账号工作，不提供应用内多账号管理。

重启应用后，原有待保存表单不能可靠恢复，相关记录会变为“需要处理”。不要凭旧截图继续保存；先检查目标平台，再重新准备。普通关闭和重启不会清空本地模型库。

默认资料目录是项目内 `.data/`，含模型素材、任务、截图、日志和桌面外壳数据。需要备份时，先关闭 ModelPort，再复制整个目录。平台账号登录信息由默认 Chrome 配置维护，不应把 `.data/` 当成账号备份。

`MODEL_SYNC_DATA` 可指定独立工作空间；这不会自动切换 Chrome 账号。同一工作空间同时只运行一个 ModelPort 实例。
